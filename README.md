# StatusDEV

Трекер статусу розробника/команди — показує, над чим зараз хтось працює і наскільки він активний.

## Як це працює

Проєкт побудований як монорепозиторій із трьох частин:

- **`web/`** — інтерфейс, де користувач бачить і оновлює свій статус (наприклад, "працюю над задачею X", "на зустрічі", "офлайн").
- **`api/`** — бекенд, який приймає оновлення статусу від `web`, зберігає їх у базі даних і віддає поточні статуси всіх користувачів/команди.
- **`shared/`** — спільні типи та схеми даних (наприклад, структура статусу), якими користуються і `api`, і `web`, щоб не дублювати код.

Загальний потік: користувач змінює статус у `web` → запит іде в `api` → `api` зберігає зміну в базі → всі, хто дивиться дашборд, бачать оновлений статус.

Наразі це базовий каркас проєкту — логіка ще не реалізована.
